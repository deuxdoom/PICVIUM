00. 이 문서의 역할
======================================================================

이 문서는 PICVIUM 이미지 뷰어·에디터의 이름에 담긴 의미, 공식 문구,
브랜드 서사, 로고 시스템, 컬러와 타이포그래피, UI/UX 원칙, 실제 사용 문구,
개발 리소스 관리 규칙을 하나의 기준으로 묶은 브랜드 명세서다.

본 문서는 디자인 및 구현 방향을 제시하는 브랜드 기준안이다. 현재의 CI 시안,
워드마크 이미지, SVG 복원 작업은 후속 검증이 필요한 상태이며, 본 문서의 치수와
색상은 '권장 디자인 토큰'이지 원본 이미지에서 계측한 확정 수치가 아니다.

제품 표기: PICVIUM (공식 영문), Picvium (UI의 타이틀 표기 허용), 픽비움 (국문)
제품 범주: Cross-Platform Image Viewer & Editor
브랜드 핵심 메시지: 사진을 비우다, 기억을 남기다.
브랜드 영문 메시지: Clear the clutter. Keep the moments.

01. 네이밍과 브랜드 철학
======================================================================

PICVIUM은 사진을 연상시키는 영어 'PIC(Picture)'과 한국어 '비움'을
결합해 의미를 부여한 브랜드 이름이다. '비움'은 삭제 그 자체가 아닌 선택,
정돈, 집중의 행위를 의미한다. 브랜드 의미는 한국어 사용자에게 직관적이지만,
영어 이름 그 자체가 영어권에서 '비움'의 사전적 의미를 가진 것은 아니다.
따라서 영문 홍보에는 브랜드 철학을 자연스러운 메시지로 함께 설명한다.

핵심 정의:
  "비움은 무엇을 버릴지를 결정하는 행위가 아니라,
   무엇을 남길지를 선택하는 과정이다."

철학의 세 축:
  1) 기록하다: 사진을 통해 순간과 기억을 채운다.
  2) 돌아보다: 쌓인 이미지를 탐색하고 비교하며 의미 있는 장면을 고른다.
  3) 남기다: 불필요한 것을 덜어내고 소중한 순간을 더 선명하게 보존한다.

제품은 사진을 무조건 지우라고 권하는 도구가 아니다. 사진을 빠르고 정확하게
보고, 안전하게 정리하고, 필요한 만큼 수정할 수 있도록 돕는다. '비움'이란
디지털 공간을 정돈하고 시선과 기억에 여백을 만드는 경험이다.

03. 브랜드 스토리 — 공식 장문
======================================================================

[국문]

우리는 매일 수많은 순간을 사진으로 기록합니다.

소중한 추억부터 스쳐 지나가는 일상까지, 셔터를 누를 때마다 우리의 디지털
공간은 조금씩 채워집니다. 하지만 시간이 흐르면서 수천, 수만 장의 사진이
쌓이고, 정작 간직하고 싶은 순간은 그 속에 묻혀버리기도 합니다.

PICVIUM(픽비움)은 사진을 뜻하는 PIC(Picture)과 한국어의 '비움'에서
의미를 가져온 이름입니다.

사진을 찍으며 순간을 채우는 일만큼, 쌓인 사진을 돌아보고 하나하나
정리하며 비워내는 과정 역시 중요하다는 생각에서 출발했습니다.

여기서 비움은 단순한 삭제를 의미하지 않습니다.

비슷한 사진들 사이에서 가장 마음에 드는 한 장을 고르고, 불필요한 이미지를
덜어내며, 소중한 기록을 더 선명하게 남기는 일. 비움은 잊기 위한 행위가
아니라, 진정으로 기억하고 싶은 것을 선택하는 과정입니다.

PICVIUM은 빠르고 직관적인 이미지 탐색과 편집, 효율적인 사진 관리를 통해
이러한 과정을 더욱 편안하고 즐겁게 만들고자 합니다.

더 많은 기능을 채워 넣기보다 꼭 필요한 기능을 정교하게 다듬고, 복잡한
인터페이스 대신 이미지 자체에 집중할 수 있는 공간을 지향합니다.

사진을 채우는 순간부터, 비워내고 남기는 시간까지.

PICVIUM은 단순히 이미지를 보여주는 프로그램을 넘어, 우리가 기록한
순간들을 더 의미 있게 마주할 수 있도록 돕는 이미지 뷰어이자 에디터입니다.

사진을 비우다, 기억을 남기다.

05. 브랜드 인격과 핵심 가치
======================================================================

가치 1 | CLARITY — 명료함
  좋은 이미지를 더 잘 보이게 한다. 인터페이스는 이미지보다 앞서지 않는다.

가치 2 | EASE — 가벼움
  빠른 실행, 직관적인 이동, 짧은 동선과 사용자가 예측 가능한 조작.

가치 3 | CURATION — 선택과 정리
  보기·비교·선별·정돈의 흐름이 자연스럽게 연결되도록 한다.

가치 4 | CRAFT — 정교한 실용성
  크롭·리사이즈·색상 보정·변환 같은 기본 기능을 세심하게 완성한다.

가치 5 | OWNERSHIP — 통제권과 안전
  원본과 메타데이터를 존중하고, 변경 전에 사용자에게 선택권을 제공한다.

가치 6 | FOCUS — 여백의 미학
  기능이 많아도 첫 화면은 조용하고, 필요한 도구만 적절한 순간에 나타난다.

브랜드 톤: 차분함 / 정돈됨 / 신뢰감 / 정밀함 / 진보적이되 과시적이지 않음.
피할 톤: 과도한 AI 강조 / 강요하는 정리 / 불필요한 애니메이션 / 과장 광고.

06. CI — 심볼(Logo Icon) 규격
======================================================================

기본 콘셉트:
  짙은 그래파이트·네이비의 라운드 사각 배경 + 커스텀 P 모노그램
  + P 내부의 원형 카메라 조리개 + 네 귀퉁이 뷰파인더 브래킷.

형태 규칙:
  - 기존 승인된 원본 이미지의 실루엣, 비율, 렌즈 위치, 조리개 형상을 우선한다.
  - 단순한 폰트 P, 흔한 카메라 기호, 범용 셔터 이모지로 대체하지 않는다.
  - 내부의 조리개 날 개수와 각도는 원본에 맞춰 확인 후 SVG path로 구현한다.
  - 코너 브래킷 4개는 각각 독립 그룹으로 제어한다.
  - 원본 다크 아이콘이 마스터 기준이며, 라이트/고대비판은 같은 도형을 유지한다.

자산 변형:
  picvium-icon-master.svg    : 마스터 다크/기본
  picvium-icon-light.svg     : 라이트 UI 대응
  picvium-icon-highcontrast.svg : 접근성 대비 강화
  picvium-icon-small.svg     : 16~64px용 세부 단순화 버전

작은 크기에서는 조리개 내부 선을 미세 단순화할 수 있으나 모노그램 실루엣은
동일하게 보존한다. 앱 아이콘은 16/24/32/48/64/128/256/512/1024px에서 확인한다.

07. CI — 워드마크(Wordmark) 규격
======================================================================

공식 글자: Picvium (P 대문자, 이하 소문자)
공식 프로젝트/저장소 표기: PICVIUM

핵심:
  - 전용 커스텀 워드마크의 문자별 외곽선을 그대로 유지한다.
  - 기성 폰트로 텍스트를 다시 쓰는 행위는 금지한다.
  - P/i/c/v/i/u/m의 곡률과 자간, 두 i의 점 크기·위치를 유지한다.
  - 첫 번째 i의 점은 선명한 시안 포인트이다.
  - 두 번째 i의 점은 주변 테마와 조화를 이루는 별도 명암으로 표현한다.
  - 왼쪽 P는 깊은 블랙/네이비, 오른쪽 m으로 갈수록 은은한 슬레이트 계열로
    밝아지는 연속적인 수평 그래파이트 그라데이션을 기본으로 한다.
  - 글자마다 그라데이션을 반복 적용하지 않는다.
  - 라이트·다크·고대비에서는 글자의 형태를 보존한 채 명암과 색상만 최적화한다.

SVG 권장:
  <path> 기반 아웃라인, 공유 그라데이션, 개별 문자 그룹,
  gradientUnits="userSpaceOnUse" 사용.

락업(Lockup):
  A. 아이콘 단독 — 앱 아이콘, 작업표시줄, 파일 연결, 작은 UI 영역
  B. 워드마크 단독 — 홈페이지, README, 시작 화면
  C. 아이콘 + 워드마크 — About, 설치 화면, 공식 소개 이미지
  D. 슬로건 포함 — 브랜드 캠페인, 공식 CI 보드 및 소개 페이지

보호 영역: 시각적으로 로고가 답답하지 않도록 충분한 여백 확보.
확정된 SVG 마스터를 기준으로 실제 비율과 최소 사용 크기를 후속 수치화한다.

금지: 회전·찌그러짐·임의 색상 변경·조리개 교체·점 제거·과도한 발광·
      복잡한 사진 위 무대비 배치·승인되지 않은 가짜 로고 사용.

특히 아이콘 및 워드마크의 정확한 그라데이션 정지점(stop)은 원본 픽셀 분석

  뉴트럴/그래파이트 75~85% + 시안/블루 10~20% + 바이올렛 5% 내외.

  색상만으로 상태를 전달하지 않는다. 초점선과 텍스트 대비를 높인다.

주의:
  브랜드 컬러 = 모든 UI 요소에 적용하는 색이 아니다.
  사용자 이미지의 원래 색을 정확히 보여주는 것이 뷰어의 우선순위다.

09. UI/UX 디자인 원칙
======================================================================

기본 표현: 프레임리스, 심플, 정교함, 빠른 반응, 사용자 중심 커스터마이즈.

1) 이미지를 중심에 둔다.
   화면 중앙 이미지 영역을 가장 크게 확보하고 패널은 접을 수 있게 한다.
2) 첫 화면은 조용하다.
   상단에는 가장 필요한 동작만 배치하며 사용자가 툴바 버튼을 직접 선택한다.
3) 탐색은 끊기지 않는다.
   키보드·마우스·휠로 폴더 내 사진을 빠르게 전환한다.
4) 확대는 직관적이다.
   클릭/휠 확대, 확대 상태 드래그 이동, Fit/100% 전환을 자연스럽게 제공한다.
5) 정보는 요청할 때 보여준다.
   EXIF 사이드바는 선택 사항, 하단 상태바는 핵심 정보만 간결하게 제공한다.
6) 반복 작업을 줄인다.
   비율 프리셋 크롭·리사이즈, 일괄 변환·회전 등의 흐름을 단순하게 만든다.
7) AI는 사용자를 대신하지 않는다.
   AI 업스케일링은 별도 기능으로 분리하고 원본·출력 결과를 비교할 수 있게 한다.
8) 비움은 안전해야 한다.
   삭제·덮어쓰기·일괄 편집에는 미리보기·확인·복구 가능성을 설계한다.
9) 세 운영체제에서 납득 가능한 경험.
   OS 전용 셸 통합은 플랫폼별 모듈로 분리하고 공통 기능은 동일하게 유지한다.
10) 접근성은 꾸밈이 아니다.
    고대비, 키보드 탐색, 포커스 표시, 화면 배율을 고려한다.

제품의 '비움' 철학을 기능으로 연결하는 예시:
  비슷한 이미지 비교 → 남길 사진 선별
  즐겨찾기/평점/분류 → 소중한 사진 재발견
  크롭 → 불필요한 주변 요소 정돈
  리사이즈/포맷 변환 → 목적에 맞게 간결하게 정리
  원본 보존 → 추억을 지키는 안전한 편집

상기 기능 연결은 제품 방향이며 구현 완료를 주장하지 않는다.

10. 타이포그래피 및 디자인 언어
======================================================================

워드마크는 반드시 승인된 커스텀 벡터 자산을 사용한다.
일반 UI에는 라이선스 검토를 거친 가독성 좋은 산세리프를 적용한다.
후보: Inter(영문), Noto Sans KR(한글) 등. 글꼴은 최종 포함/번들 정책 확인.

레이아웃:
  - 8px 스페이싱 그리드 기반으로 일관성을 유지한다.
  - 둥근 모서리는 절제해 사용한다.
  - 핵심 컨트롤은 충분한 클릭 영역을 확보한다.
  - 사진 색을 왜곡할 정도의 반투명 오버레이·발광을 피한다.
  - 아이콘은 단순한 일관된 스트로크 스타일을 기본으로 한다.
  - 불필요한 애니메이션보다 빠른 피드백을 우선한다.

사진/홍보 비주얼:
  여백, 따뜻한 기록, 고요한 풍경, 일상의 결정적 순간, 정돈된 디지털 공간.
  지나치게 차갑고 공격적인 SF 게임 UI처럼 보이지 않도록 균형을 잡는다.

11. 브랜드 보이스 & 표현 규칙
======================================================================

말투: 담백하고 명확하다. 소프트웨어 사용자에게 신뢰를 준다.
기조: '사진을 잘 보게 해준다'가 주제이며 '사진을 모두 지우라'가 아니다.

사용할 표현:
  더 선명하게 / 소중한 순간 / 덜어내다 / 돌아보다 / 정리하다 / 남기다

피할 표현:
  무조건 삭제 / 완벽한 자동화 / 단 한 번에 모든 사진 정리 / 세계 최고 / 완벽한 AI

잘못된 예: "사진을 모두 지우고 공간을 확보하세요."
개선된 예: "지금 남기고 싶은 사진에 더 쉽게 집중하세요."

잘못된 예: "AI가 당신에게 필요한 사진을 결정합니다."
개선된 예: "이미지를 비교하고 선택하는 과정은 사용자가 주도합니다."

13. 개발·운영 환경과 CI 관리
======================================================================

개발 프로젝트·임시 작업의 절대 경로는 로컬 개발 지침에서 관리한다.
비공개 구현·개발 기록은 공개 배포 자료와 분리한다.
공개 브랜드 참고 자료: docs/brand
공개 웹 자산: docs/assets/brand (승인된 마스터의 파생본만 사용)

개발상의 경로 제약은 릴리스 실행 환경에 전파하지 않는다. 설치된 PICVIUM은
F 드라이브가 없는 Windows/macOS/Linux에서도 실행되어야 한다. 런타임 설정,
캐시, 임시파일은 OS 표준 사용자 데이터 경로 또는 포터블 모드 정책을 따른다.

GitHub 공개 저장소는 실행 파일·문서 공개용으로 사용하고 비공개 소스코드를
커밋하지 않는다는 운영 원칙을 별도 검증 절차로 관리한다. 저장소가 Public인
경우 이미 커밋한 소스는 .gitignore만으로 과거 기록에서 삭제되지 않는다.

라이선스/배포 정책 (현재 의도): 독점 소프트웨어, 소스 비공개, 개인 비상업적
사용 무료, 무단 재배포 및 상업적 이용 금지. 구체적인 EULA는 별도로 작성한다.
서드파티 라이브러리 및 AI 모델의 저작권·사용조건은 본 정책과 별개로 준수한다.

14. 브랜드 검증 체크리스트
======================================================================

[ ] PICVIUM / 픽비움 표기가 정확하다.

[ ] 워드마크는 폰트 대체가 아닌 커스텀 path를 사용한다.
[ ] 워드마크의 좌→우 그래파이트 그라데이션이 살아 있다.
[ ] 첫 번째 i의 시안 점과 두 번째 i의 점이 구분된다.
[ ] 다크·라이트·고대비에서 충분한 명암 대비가 있다.
[ ] 16px부터 큰 화면까지 아이콘이 알아볼 수 있다.
[ ] 원본 이미지 색상은 브랜드 UI 색상 때문에 변경되지 않는다.
[ ] 비움 철학을 안전한 정리·선택과 연결한다.
[ ] 사진 삭제와 덮어쓰기는 정확한 의미·충분한 피드백을 제공한다.
[ ] CI에 사용한 생성형 시안과 최종 승인 SVG가 혼동되지 않는다.
[ ] 배포 패키지에 개발용 경로나 민감한 파일이 포함되지 않는다.

16. 팀·코딩 에이전트용 요약 지시문
======================================================================

PICVIUM은 'PIC(Picture) + 비움'이라는 브랜드 철학을 가진 이미지 뷰어·에디터다.
사진을 쌓는 행위만큼, 비교·선별·정리하며 중요한 장면을 남기는 경험을 존중한다.
UI는 빠르고 차분하고 직관적이어야 하며 이미지 자체가 중심이 되어야 한다.
CI는 P+렌즈+뷰파인더 아이콘, 좌→우 그래파이트 그라데이션 워드마크, 제한적인
시안·블루·바이올렛 액센트를 사용한다. 브랜드 CI를 재디자인하지 말고 승인된
기준 자산을 재사용한다. 다크/라이트/고대비에서는 색상과 대비만 최적화한다.
원본 사진의 색과 사용자 데이터의 안전을 UI 연출보다 우선한다.

공식 슬로건:
  "사진을 비우다, 기억을 남기다."
  "Clear the clutter. Keep the moments."
