Application captures
Current Release Picvium UI assemblies rendered with the native Windows desktop backend
in an isolated capture harness (2026-10-14), using the original distribution's native libraries.
Lossless PNG at actual monitor scaling; client visual only. No Computer Use, interface
reconstruction or image editing. Assembly/native/image hashes and method: screens/source-info.json
Main photograph: SAMPLE_01.jpg, selected by the copyright holder; AI source: SAMPLE_09.png.
The batch output field uses the common public Pictures/Converted directory as an example;
no file conversion, inference or image save was run for these dialog captures.

Functional viewer captures (viewer-thumbnails.png, viewer-crop.png, viewer-actual-size.png)
Current Release production assemblies rendered with the same native Windows backend in
an isolated capture harness. Nine actual Eric Park / @deuxdoom photos form the folder
filmstrip; the white-curtains exhibition photo is selected, with the EXIF panel and
information bar visible. Downloaded photos have no EXIF camera values, and the UI shows
them as unavailable. The crop screen uses the coffee photo with a real 1607 x 1236 px
selection routed through production Avalonia input handlers. The yellow rose screen uses
the production 1:1 actual-size action at 100%. Apply/Save were never executed.
Original SAMPLE and photo bytes are unchanged. Captures were exported directly as lossless
PNG, with no image editing or reconstructed interface text. Per-capture assembly/native
hashes, individual Unsplash source URLs/hashes and method: screens/source-info.json,
featureCapture. Numbered website markers are HTML overlays; enlarged PNGs are unmodified.
