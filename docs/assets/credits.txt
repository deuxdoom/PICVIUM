Application captures (Picvium 1.0.2, 2026-10-18)
viewer-photo, viewer-exif, viewer-thumbnails, viewer-actual-size, toolbar, settings, upscale,
editor-levels, editor-curve, editor-mosaic, editor-resize (.png; large ones also .webp)
Production Release assemblies of the distributed 1.0.2 build, rendered by an isolated native
Windows Avalonia capture harness. Lossless PNG client visuals at the actual 150% monitor
scaling; no Computer Use screenshots, OS input, retouching, resampling or rebuilt interface text.
Editor captures show unapplied previews; Apply and Save were never run and no photo was changed.
Each feature uses a different main photo: hero SAMPLE_01, EXIF unsplash_07, levels unsplash_20,
curve unsplash_04, mosaic unsplash_11, resize unsplash_08, filmstrip unsplash_03, 1:1 unsplash_13,
AI SAMPLE_09. EXIF values come from the files; no image or EXIF value was invented.
AI upscale GPU line: shows "NVIDIA GeForce RTX 5090" at the copyright holder's request. The capture
PC has an RTX 4080 SUPER, so this device result was supplied to the real dialog instead of the live
Vulkan probe. The dialog still renders it; no pixels were edited.
batch.png is the 2026-10-14 capture; a 1.0.2 rerun produced identical pixels, so it is kept.
WebP previews are lossless conversions verified to decode to identical RGBA pixels; the page
enlarges the PNG. Numbered markers on the page are HTML overlays, not part of the captures.
Per-capture hashes, source photo hashes and states: screens/source-info.json
