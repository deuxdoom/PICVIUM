# PICVIUM
A modern, fast, cross-platform image viewer and editor with intuitive photo editing, batch processing, and AI-powered upscaling.

*Clarity in Every View*

> **Status: in development.** No public build has been released yet.
> Downloads will be published on the [Releases](https://github.com/deuxdoom/PICVIUM/releases) page.

## Planned features
- Fast viewing: fit / 100% zoom, pointer-anchored wheel zoom, pan and keyboard navigation
- Formats: JPEG, PNG, WebP, AVIF, BMP and GIF — each format is enabled only after it has been verified on each platform
- EXIF / file properties panel and a status bar showing capture, creation and modification dates separately
- Editing: crop, resize, rotate / flip, basic color adjustments, undo / redo — originals are never overwritten without confirmation
- Save As with real re-encoding, batch convert and batch rotate
- AI upscaling as a dedicated tool, separate from regular resizing
- Frameless window with a customizable toolbar and shortcuts, light / dark themes
- Windows integration: set as wallpaper, file associations
- Korean and English user interface

## Platforms
Windows x64 is the first target. macOS and Linux builds are planned; a platform will be listed as supported only after its release build has been tested.
